# 계획 대비 변경 기록

허용오차·기대값·범위를 바꿀 때 이전 값, 새 값, 근거를 남긴다.

## 2026-11-16 — Stage 1의 "나머지 크레이트 공개 타입 동결"을 하지 않음

- 이전: Stage 1에서 모든 크레이트의 공개 타입·트레잇 시그니처를 본문 없이 먼저 커밋한다.
- 변경: foundation과 api 크레이트만 확정하고, 나머지는 각 크레이트를 구현할 때 확정한다.
- 근거: 동결은 여러 구현 에이전트가 동시에 작업할 때 서로의 인터페이스를 건드리지 않게 하려는 장치였다. 지금은 한 흐름으로 순차 구현하므로 미리 고정하면 추측으로 쓴 시그니처를 다시 고치는 일만 늘어난다. 플러그인 경계(api 크레이트 2개)는 계획대로 확정했다.

## 2026-11-16 — 구현 순서를 스케치 우선으로 변경

- 이전: Stage 2a에서 솔버·로봇·플래너·궤적·카메라·문서를 함께 진행.
- 변경: 스케치 쪽(솔버 → 스케치 → 문서 → 도구 → 뷰포트 → UI)을 먼저 화면에 보이는 데까지 완성하고, 로봇·경로 계획을 그다음에 붙인다.
- 근거: 사용자가 가장 먼저 요청한 것이 "UI, 스케치, 치수·구속조건"이며, 화면으로 확인할 수 있는 결과를 빨리 내기 위해서다. 범위와 게이트는 그대로다.
