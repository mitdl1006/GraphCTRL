# M2-1 모델 트리 편집 — 수용 기준 (QA)

근거: PLAN.md 9.1(모델 트리). 이 문서는 구현자가 고칠 수 없는 수용 기준이다. 기능이 브랜치에 올라오면 각 항목을 헤드리스 세션
테스트(`gc_session/tests/`)와 kittest(`gc_app/tests/`)로 옮긴다. 상태 열: ⬜ 기능 없음 · 🟨 일부 · ✅ 테스트 있음.

공통 불변식(모든 시나리오에 적용): ① 실행 취소∘다시 실행 = 항등(`same_content`) ② 거부된 편집은 문서·리비전·히스토리를 바꾸지 않는다
③ 어떤 입력에도 패닉 없음 ④ 저장∘열기 = 항등(이름·억제·순서 포함) ⑤ 트리의 선택은 뷰포트 선택과 같은 항목을 가리킨다.

## T2 억제 (Suppress)

| # | 시나리오 | 기대 |
|---|---|---|
| T2.1 | 스케치 억제 | 뷰포트에서 사라지고 솔버·DOF 계산에서 빠짐. 억제 해제 시 이전 상태 그대로(좌표 비트 동일) |
| T2.2 | 스케치를 억제하면 그 점에 붙은 웨이포인트 | 웨이포인트는 삭제되지 않고 "끊김/오류" 배지, 경로는 오래됨 → 계획이 사유를 보고. 해제하면 복구 |
| T2.3 | 바디/설비 억제 | 충돌·계획에서 빠진다(투명도와 다름: 투명은 여전히 장애물). 해제하면 다시 장애물, 기존 계획은 오래됨 |
| T2.4 | 로봇 억제 | 그 로봇을 쓰는 경로는 계획 불가로 표시. 다수 UR에서는 스케줄러 후보에서 빠진다 |
| T2.5 | 억제는 Undo 1단계, 저장·열기에서 유지 | |
| T2.6 | 이미 억제된 항목을 가진 항목 억제(상위 억제) | 하위는 "상위 억제됨"으로 표시, 해제 순서 무관하게 일관 |
| T2.7 | 억제된 항목의 선택·치수 편집 시도 | 선택은 되지만 편집 명령은 막힘(안내), 문서 불변 |

## T4 스케치 편집(더블클릭·우클릭 "스케치 편집")

| # | 시나리오 | 기대 |
|---|---|---|
| T4.1 | 더블클릭으로 편집 진입 → 선 추가 → 종료 | 종료 시 종속 항목(웨이포인트·돌출 피처·필드)이 갱신되고 경로는 오래됨. Undo 1회로 편집 전체 |
| T4.2 | 편집 중 다른 항목 더블클릭 | 현재 스케치가 정상 종료되거나 안내. 반쯤 그려진 선은 버려진다 |
| T4.3 | 편집 중 Undo | 스케치 안에서만 되돌려진다. 모드 이탈 규칙은 기존 S 시나리오와 같다 |
| T4.4 | 소비된 스케치(피처가 사용) 편집 | 허용, 프로파일이 열리면 피처에 오류 배지, 닫으면 해소 |
| T4.5 | 불러온 설비의 면 위 스케치(후속) | 설비를 바꿔 불러오면(면 사라짐) 스케치에 오류 배지, 삭제하지 않는다 |
| T4.6 | 편집 중 저장 | 진행 중인 작업을 포함하지 않거나 한 단계로 확정 — 어느 쪽이든 열었을 때 반쯤 만든 상태가 아니다 |

## T5 삭제와 종속 안내

| # | 시나리오 | 기대 |
|---|---|---|
| T5.1 | 종속 없는 항목 삭제 | 삭제, Undo로 같은 ID·위치(트리 순서 포함)로 복원 |
| T5.2 | 종속 있는 항목 삭제(좌표계 ← 웨이포인트, 웨이포인트 ← 경로, 로봇 ← 경로, 스케치 점 ← 웨이포인트) | 삭제 전 종속 목록을 보여 주는 안내(이름 포함). 진행하면 종속 항목은 규칙대로 처리(기존: 거부 또는 분리) — **조용히 사라지지 않는다** |
| T5.3 | 안내에서 취소 | 문서 불변 |
| T5.4 | 다중 선택 삭제(종속 관계에 있는 항목 함께) | 한 번의 안내, Undo 1단계, 일부만 삭제되는 부분 상태 없음 |
| T5.5 | 삭제 후 Undo, 다시 삭제 | 같은 결과 |
| T5.6 | 소비된 스케치 삭제 | 피처가 있으면 함께 삭제할지 묻는다(기본은 거부) |
| T5.7 | 원점·불러온 설비의 고정 참조 삭제 | 원점은 불가, 설비는 "설비 제거"로만 |
| T5.8 | 계획 중(작업 스레드)인 경로·로봇 삭제 | 계획이 취소되고 늦게 도착한 결과를 버린다(삭제된 ID에 결과가 붙지 않음) |

## T6 선택 동기화·표시

| # | 시나리오 | 기대 |
|---|---|---|
| T6.1 | 트리 클릭 ↔ 뷰포트 선택 일치, Ctrl 다중 선택 | 양방향 |
