# 사용자 PC 수동 확인 체크리스트 (인벤터식 조작)

샌드박스에서는 실제 모니터·마우스·한글 IME·그래픽 드라이버로 확인할 수 없는 것들입니다. 자동 테스트(kittest·헤드리스)가 이미 덮는 동작이라도
**손으로 해 보았을 때 인벤터 사용자가 같은 손맛으로 느끼는지**를 확인합니다. 기준은 Autodesk 2026 도움말
(<https://help.autodesk.com/cloudhelp/2026/ENU/Inventor-Help/files/>)이며 각 항목에 근거 문서를 적었습니다. 결과는 표의 "결과" 칸에
✅ / ❌ / ⚠(메모)로 적고, ❌·⚠는 재현 절차와 함께 `docs/handoff/qa.md`에 옮겨 주세요.

준비: `cargo run -p graphctrl --release` (Windows와 Linux 각각), 해상도 1920×1080과 125 % 배율 한 번씩, 한글 입력기 켠 상태와 끈 상태.
시작은 "파일 > 예제 열기 (UR5e 셀)"을 쓰고, 항목마다 "새로 만들기"로 돌아와도 됩니다. 각 항목은 5분 안에 끝나도록 잘랐습니다.
