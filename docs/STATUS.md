## 작업 순서

스케치 쪽을 먼저 화면까지 완성했고(2D → 3D), 이어서 로봇·경로 계획 쪽을 화면까지 연결했다. 지금은 두 쪽이 이어져
"스케치한 선을 로봇이 따라간다"가 동작한다. 다음 후보:

1. 브라우저 아이콘 행
2. 3D 스케치 점 드래그·글리프, 트림 도구
3. 설정(내비게이션 프리셋·단위), 플래너 플러그인 래핑, 큰 메시 비동기 로드

이미 된 것(최근): 작업 좌표계(3점 축, 6축 좌표), 좌표계 기준 웨이포인트, 프로젝트 저장(메시 동봉)·최근 항목·자동 저장
복구, 가시성·투명도, 선택·호버 강조·컨텍스트 메뉴, 이동/회전 기즈모(바디·로봇·웨이포인트·좌표계), Fusion풍 표시
(반구 조명·하이라이트, 피처 엣지 1픽셀 선 한 번의 드로, 그라데이션 배경), 웨이포인트 고스트 로봇(선택·호버한 웨이포인트의 IK 자세를 반투명으로, 문제가 있으면 붉게, 속성 창에
도달 여부·관절값), 경로의 웨이포인트 순서 편집(↑↓·빼기·추가, 실행 취소 한 단계), 툴 형상(원기둥·상자·구·메시 파일, 끝 링크의 일부로 충돌 검사·계획에 반영, "TCP를 툴 끝으로"), 파일 > 예제 열기(UR5e·기둥·작업 좌표계·웨이포인트 2개·계획된 경로), 도움말 > 라이선스(앱·Jetendard·UR 설명 고지), 경로 궤적 클릭 선택·강조(선택한 경로의 웨이포인트에 순서 번호),
관절값 웨이포인트 편집·다시 저장, 직선 이동 TCP 속도 상한(궤적을 고르게 늦춤, 최대 TCP 속도 표시), UR3e/UR10e/UR16e(공식 YAML에서 생성한 URDF,
충돌 메시로 표시, DH 표와 FK 일치 테스트)와 리본의 "로봇 추가" 목록, 웨이포인트 기준 좌표계 표시·선택(월드/로봇 베이스(UR 티치펜던트 Base)/작업 좌표계,
바꿔도 위치 유지), 다른 좌표계에서 본 값·변환 행렬, 도구 > 포즈 변환 계산기(RPY/회전벡터/쿼터니언, 좌표 변환, A·B, A^-1), 모던 UI 정리(테마 토큰·둥근 위젯·밑줄 탭·기능별 리본 아이콘, 섹션 헤더·정렬된 속성 행·상태 칩·결과 카드,

`library://` 참조, UR IK는 DH 최소제곱 인식으로 기종 표 없음).
